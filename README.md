# Налей

Комичный симулятор придорожной АЗС. iOS/Android — цель; сейчас играбельный **веб-прототип** на том же движке, что и баланс.

## Быстрый старт

```bash
npm install
npm run dev      # игра в браузере
npm test         # проверка экономики
npm run sim      # один игровой день в консоли
npm run cli      # интерактивный CLI
```

## Структура

- `docs/GDD-REQUIREMENTS.md` — дизайн и числа
- `ROADMAP.md` — атомарный план
- `src/economy/calculations.ts` — **только расчёты** (A, цены, время заправки, quote колонки)
- `src/game.ts` — игровой цикл (очередь, колонки, бензовоз, магазин)
- `web/` — UI (canvas + кнопки), портрет, RU/EN

## Игра

- Машины сами едут на свою колонку (92 / 95 / 100 / ДТ)
- Тап по машине в очереди на canvas → «Приоритет» / «Удержать»
- Заказ бензовоза, постройка колонок, магазин, заправщик
- Пауза при сворачивании вкладки, автосейв в `localStorage`
